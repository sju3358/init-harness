# 구현 (Codex는 실행하지 않음)

구현은 Claude 전용이다. 원본은 `.claude/skills/implement/SKILL.md`이며 Codex는 이 절차를 실행하지 않는다. Codex의 `src/main`·빌드 파일 편집은 훅이 차단한다. 한 티켓의 구현을 한 모델이 맡아 코드 스타일을 일관되게 유지하기 위함이다.

- 검증·테스트 중 발견한 소스 결함은 고치지 않고 `HANDOFF.md` "구현 수정 요청"에 버그 리포트로 적는다: 실패한 시나리오, 관련 REQ·PRD, 기대값(문서 원문), 실제값, 재현 방법, 의심 지점(`파일:줄`).
- 다음 행동을 `Claude implement(구현 수정 요청 반영)`으로 적고, 사용자에게 같은 폴더의 Claude 세션에서 "구현 수정 요청 반영해"라고 하도록 안내한 뒤 멈춘다.
