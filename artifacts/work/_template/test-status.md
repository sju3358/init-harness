# F-## 테스트 상태

Codex가 TC(시나리오)별 최신 실행 상태를 유지한다. 재실행 범위는 이 표로 정한다(`test-verify` "재실행 범위").

- 마지막 전체 회귀: (일시, 커밋, 결과. 없으면 `미실행`. 완료 판정에는 이 실행이 실패 0건이고 이후 소스·테스트 변경이 없어야 함)

| TC | REQ | 테스트 (`파일:메서드`) | 관련 소스 | 상태 | 마지막 실행 (일시·커밋) |
| --- | --- | --- | --- | --- | --- |

- 상태: `PASS` · `FAIL` · `미실행`
- 관련 소스: 이 테스트가 호출하는 구현 파일. 재실행 때 `git diff <마지막 실행 커밋>..HEAD --name-only`와 대조해 PASS 항목을 다시 볼지 정한다.
- 상태는 실제 실행 결과로만 바꾼다. 실행하지 않은 TC를 `PASS`로 두지 않는다.
